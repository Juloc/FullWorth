# Database and Persistence Conventions

FullWorth uses the canonical Juloc database and persistence conventions defined in [Juloc/agent-control `docs/DATABASE_CONVENTIONS.md`](https://github.com/Juloc/agent-control/blob/main/docs/DATABASE_CONVENTIONS.md).

These rules are mandatory for all new SQL/persistence code and whenever existing persistence code is intentionally changed. Existing untouched persistence code does not require a bulk rewrite.

FullWorth-specific application:

- Existing FullWorth layering remains mandatory: database access belongs in `*Store.cs`; endpoints and unrelated services do not query the database directly.
- Backend/store code owns all create/read/update/delete behavior and business validation.
- Multi-step mutations that belong together run in one transaction.
- PostgreSQL constraints validate structural correctness; they do not perform business workflows. New/touched relationships must not use cascading referential actions to implement application behavior.
- Use PK/FK/UNIQUE/NOT NULL/CHECK constraints as validation boundaries.
- New internal relational identifiers default to `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` unless a concrete domain/distributed-ID requirement justifies another type.
- Use PostgreSQL-native types rather than text/0-1 compatibility encodings.
- Indexes are designed for real `WHERE`, `JOIN`, `ORDER BY` and reverse-FK access paths. Reuse PK/unique/composite indexes instead of adding redundant indexes.
- A composite `UNIQUE(UserId, MediaId)` already covers `UserId` and the pair; add a separate `MediaId` index only when the reverse access path is needed.
- `INCLUDE` is targeted to measured covering/index-only reads, never applied to every selected column by default.
- Prefer explicit, parameterized, inspectable SQL for new/touched performance-sensitive access where query shape matters.
- Measure important PostgreSQL queries with `EXPLAIN (ANALYZE, BUFFERS)`.
- Do not introduce a blind SQL Server-style periodic rebuild/reorganize service; use autovacuum/analyze and evidence-driven reindexing.

The canonical Agent Control document is the source of truth when this summary and the central rules differ.
